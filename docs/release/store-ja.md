# App Store 日本語原稿

アプリ名案: ATV Remote
サブタイトル案: スマホでGoogle TVを操作

## 説明

リモコンが見つからないときも、iPhoneからTVを操作。
同じネットワーク上のGoogle TV / Android TVを検索し、TV画面に表示されたコードで接続します。

接続、方向キー、決定、戻るは無料で確認できます。
買い切りのアプリ内購入で、ホーム、音量、消音、電源、動画URLの送信を解除できます。月額料金はありません。

利用には、ネットワーク設定済みでAndroid TV Remote Serviceに対応したTVが必要です。
すべての機種・機能での動作を保証するものではありません。購入前に無料の基本操作をお試しください。
TVがネットワークに接続されていない場合、このアプリだけでTVのネットワーク初期設定はできません。
電源や音量、URL起動の動作はTV・音響機器・インストール済みアプリによって異なります。

Googleおよび各動画サービスとは関係のない非公式アプリです。

## 審査メモ案

ログイン不要。TV操作には同一LAN上の対応TVが必要です。
設定・接続ガイド・IP入力・購入復元はTVがなくても確認できます。
ペアリングはTV画面の6文字コードを入力します。
アプリ内購入は非消耗型の商品 `com.entaku.atvremote.fullunlock` です。
審査用TVを用意できない場合の動作説明動画を、実機検証後に追加してください。
