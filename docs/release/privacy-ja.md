# ポケットリモコン プライバシーポリシー（公開前の原稿）

ポケットリモコンは同じネットワーク上のGoogle TV / Android TVを操作するアプリです。

## 端末に保存する情報

TVとの接続に使用する秘密鍵、証明書、ペアリングしたTVの証明書をKeychainに保存します。
送信したURLを最大30件、送信日時とともに端末内に保存します。URL履歴はアプリ内の設定から消去できます。
URL履歴は端末のバックアップ設定に従ってバックアップされる場合があります。

## 通信

TVの検索と操作にはローカルネットワークを使用します。操作内容や入力したURLは選んだTVへ送信します。
TVや動画サービスでのデータの扱いには、それぞれのサービスのポリシーが適用されます。
アプリは開発者のサーバーへ操作履歴や接続情報を送信しません。広告・アクセス解析SDKは使用していません。

## 購入

アプリ内購入と復元にはAppleのStoreKitを使用します。開発者はカード番号などの支払い情報を取得しません。
Appleが処理する購入関連情報にはAppleのプライバシーポリシーが適用されます。
