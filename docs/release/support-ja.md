# ポケットリモコン サポート

Google TV / Android TV向けの非公式リモコンです。アプリ購入後の追加課金や月額料金はありません。

## 接続できない場合

1. TV本体や付属リモコンで電源を入れ、iPhone / iPadとTVを同じWi-Fi（ネットワーク）に接続してください。ネットワーク接続中の対応TVをアプリが検索します。
2. iOSの設定で、ポケットリモコンのローカルネットワークアクセスを許可してください。
3. アプリの「もう一度検索」を押してください。見つからない場合はTVのIPアドレスを直接入力できます。
4. TV画面のペアリングコードをアプリに入力してください。

ゲストWi-Fiや端末間通信を禁止するネットワークでは接続できない場合があります。
TVがAndroid TV Remote Serviceに対応していることを確認してください。
TV自体がネットワーク未設定の場合、このアプリだけでは初期設定できません。

## 一部の操作が動作しない場合

電源・音量・消音の対応はTVや接続された音響機器によって異なります。
電源OFF時にTVがネットワーク接続を停止する場合、アプリからTVを発見したり、電源を入れたりすることはできません。TVが見つからないときは、まずTV本体や付属リモコンで電源を入れ、Wi-Fiに接続されていることを確認してください。
動画URLを開くには、そのURLに対応するアプリがTVにインストールされている必要があります。

## URL履歴を削除するには

アプリの設定から「URLの履歴を消去」を選んでください。
