# Guideline 2.1 再提出用の実機動画

Apple要求: 最新OSを実行する物理デバイスで、アプリ起動から通常の利用フローを示す画面収録。シミュレーターやスクショ用サンプル状態では代用しない。

## 撮影前

- TestFlightの1.0.0（3）を実際のiPhone/iPadにインストールする。
- 端末を、その端末で利用可能な最新の正式OSへ更新し、端末名とOSバージョンを記録する。
- 対応TVの電源を入れ、端末と同じネットワークへ接続する。TV型番・OS・Android TV Remote Serviceバージョンを記録する。
- 通知などの個人情報が録画に入らないようにする。
- iPhoneとiPad両方で基本操作を検証し、確認していない操作を成功済みと記録しない。

## 動画の流れ（目安2〜3分）

1. ホーム画面からアプリを起動するところから収録する。
2. ローカルネットワーク許可、TV検出、TV選択を示す。許可済みならその旨を説明する。
3. 初回ペアリングを示す。TV画面に表示されたコードを入力して接続する。
4. 上下左右・決定・戻る・ホームを操作し、TV側の反応も見せる。
5. 音量・消音など、使用TVで対応する操作を示す。
6. URL送信を示す場合は、TVにある対応アプリで実際に開けるURLを使い、TV側の反応を確認する。
7. 接続ガイド・設定を開く。アカウント登録・ログイン・アプリ内課金はないことを説明する。
8. 電源操作は最後に行う。電源OFFでネットワークが切れるTVはアプリから起動できないことを説明する。

端末の画面収録に加え、別のカメラで端末操作とTVの反応を同時に撮った補足動画があるとリモコン動作を確認しやすい。画面収録そのものは必須。

## 審査メモに追加する情報

- 動画URL（審査担当者がログインなしで閲覧でき、審査中に期限切れしないもの）または添付ファイル名
- 収録したアプリのバージョン・ビルド番号
- 使用した実機とOSバージョン
- TV型番・OS・Remote Serviceバージョン
- 実機で確認した機能と、機器依存で対応しなかった機能

審査メモの説明部分は `ios/ATVRemote/fastlane/metadata/review_information/notes.txt` に準備済み。
実機動画と検証結果がそろってからNotesを確定し、App Store Connectへ反映・再提出する。
